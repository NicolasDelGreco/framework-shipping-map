# Framework Shipping Availability Map

Interactive map showing the countries where Framework Computer currently ships.

Built with vanilla HTML/CSS/JS using jsVectorMap and a Carbon Design-inspired dark UI.

## Coverage

32 regions in North America, Europe, and Asia-Pacific. Except for Argentina yet ¬_¬"

## Usage

Just open `index.html` in any browser. No build step required.

## Data source

[framework.computer/shipping](https://frame.work/shipping) — last updated Q1 2025.
